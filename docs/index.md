# Global Building Inventory (globi)

GloBI changes building footprints (GIS files) into EnergyPlus shoebox models and simulates them at scale.

If you are a new user, do these steps:

1. [Install the requirements](tutorials/getting-started/requirements.md). To run without Docker, also [install EnergyPlus](tutorials/getting-started/install-energyplus.md).
2. Do the [sample-buildings tutorial](tutorials/run-simulations/tutorial.md). Then [edit the model in sbem-ui](tutorials/run-simulations/edit-components.md) and run it again.
3. Read the [workflow overview](architecture-simple.md) to see how the parts of GloBI work together.
